# مواهب

**موهبتك تستحق أن تُشاهَد**

بداية الواجهة العامة لمنصة مواهب، بتصميم عربي RTL ومتجاوب مع الجوال.

## الحالة الحالية
- واجهة تعريفية ومعرض تجريبي قابل للبحث والتصفية.
- بطاقات المعرض الحالية أمثلة شكلية وليست حسابات حقيقية.
- لا يوجد حالياً تسجيل دخول أو رفع ملفات أو قاعدة بيانات أو فحص آلي للمحتوى.
- لا تنشر المنصة محتوى مستخدمين في هذه المرحلة.

## التشغيل
افتح `index.html` في المتصفح، أو انشر المستودع على Cloudflare Pages كصفحة ثابتة.

## الخطوات التالية
1. إعداد Supabase للمصادقة وقاعدة البيانات والتخزين بعد مراجعة حدود الخطة المجانية.
2. بناء ملفات أصحاب المواهب ورفع الأعمال.
3. تصميم ضوابط الخصوصية والحماية، خصوصاً للقاصرين.
4. إضافة فحص المحتوى والبلاغات والمراجعة الإدارية قبل فتح النشر العام.

لا توجد خدمات مدفوعة مفعّلة أو مفاتيح سرية ضمن هذا المستودع.

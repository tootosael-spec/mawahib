# مواهب

**موهبتك تستحق أن تُشاهَد**

موقع عربي متعدد الصفحات ومتجاوب مع الجوال:
- `index.html`: الصفحة الرئيسية.
- `talents.html`: استكشاف المواهب المنشورة.
- `account.html`: التسجيل وتسجيل الدخول وإدارة مواهب المستخدم ورفع الصور للمراجعة.
- `about.html`: التعريف بالمنصة.

## البيانات والحسابات
يعتمد الموقع على Supabase للمصادقة والبيانات والتخزين الخاص. تبقى ملفات المواهب الجديدة والصور بانتظار المراجعة قبل عرضها. لا تغيّر هذا التحديث قاعدة البيانات أو إعدادات التخزين.

## النشر
الموقع ملفات HTML ثابتة مع ملف JavaScript مشترك `app.js` وملف تنسيق `styles.css`. يمكن نشره على Cloudflare Workers/Pages وفق إعداد المشروع الحالي.
